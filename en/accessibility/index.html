Accessibility Statement

Our commitment

The Central Taiwan Science Park Bureau, National Science and Technology Council, wants everyone to be able to use this website. The site is designed and tested against the Ministry of Digital Affairs' Web Accessibility Guidelines, aiming for level AA, and we keep improving it.

Access keys

Each area of the page starts with an anchor marked “:::”. Use these shortcuts to jump to it:

Access key shortcuts
ShortcutAreaContains
Alt + UHeader areaSite name, main menu and site links
Alt + CMain content areaThe main content of each page
Alt + ZFooter areaSite links, contact details and map

Browsers differ slightly: in Firefox use Shift + Alt + letter; on macOS use Control + Option + letter.

Using the keyboard

  • The first item on every page is “Skip to main content”. Press Tab to reveal it.
  • Tab moves to the next link or button, Shift + Tab moves back, and Enter opens it.
  • Move through the main menu with Tab; press Enter to open or close a submenu.
  • To change the text size, use your browser's zoom (Windows: Ctrl + plus/minus; macOS: Command + plus/minus).
  • For an overview of the whole site, see the Sitemap.

Other features

  • Images have text alternatives; charts come with a text description or a table.
  • Links that open in a new window say so.
  • Text and background colours meet the contrast requirements, and colour is never the only way information is shown.
  • All content can be read without JavaScript.

Known limitations

The report PDFs under “Report Download” were exported from the original print layouts, so the reading order and tagging of some files may be incomplete. Please contact us if you need another format.

Feedback

If anything on this site is hard to use, please tell us through the feedback form (opens in a new window) or call +886-4-2565-8588. We will get back to you as soon as we can.
