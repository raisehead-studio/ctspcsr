無障礙聲明

我們的承諾

國家科學及技術委員會中部科學園區管理局致力讓每一位使用者都能順利取得本網站的資訊。 本網站依數位發展部「網站無障礙規範」設計與檢測，以 AA 等級為目標， 並持續改善。

網站定位點（導盲磚）

本網站在各區塊開頭設有定位點「:::」，可用快速鍵直接跳到該區塊：

網站定位點快速鍵
快速鍵位置說明
Alt + U上方功能區塊網站名稱、主選單與網站導覽等連結
Alt + C中央內容區塊各頁面的主要內容
Alt + Z下方功能區塊網站連結、聯絡資訊與地圖

不同瀏覽器的組合鍵略有不同：Firefox 請用 Shift + Alt + 字母； macOS 請用 Control + Option + 字母。

鍵盤操作

  • 每頁第一個可操作的項目是「跳到主要內容區塊」，按 Tab 鍵即可看到。
  • Tab 鍵移到下一個連結或按鈕，Shift + Tab 回到上一個，Enter 鍵開啟。
  • 主選單可用 Tab 鍵移動，按 Enter 展開或收合子選單。
  • 要調整文字大小，可使用瀏覽器的放大縮小功能（Windows：Ctrl + 加號／減號；macOS：Command + 加號／減號）。
  • 完整的網站結構請見網站導覽。

其他設計

  • 圖片均提供替代文字，資料圖表另附文字說明或表格。
  • 另開新視窗的連結都會告知使用者。
  • 文字與背景的顏色對比符合規範，不只用顏色傳達資訊。
  • 網站內容不需 JavaScript 即可瀏覽。

已知限制

「報告書下載」中的歷年報告書 PDF 由原始排版檔轉出，部分檔案的閱讀順序與標記可能不完整。 如需其他格式，歡迎與我們聯絡。

意見回饋

若您在使用本網站時遇到任何障礙，歡迎透過 意見回饋（另開新視窗） 或來電 04-2565-8588 告訴我們，我們會儘快處理。
